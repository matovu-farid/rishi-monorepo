## Deviations from ARCH (with rationale)

All resolved per the drift-resolution guidance in the coder prompt (UI-SPEC is canonical when the spec, ARCH, or tests disagree).

1. **`motion.timing.fast → motion.duration.fast = 200`** (UI-SPEC §5). The token module exposes `motion.duration.{fast,normal,slow}` instead of `motion.timing.{fast,normal,slow}` because the failing test in red phase pinned `motion.duration.fast`. The 200ms value (UI-SPEC) is used rather than the prompt's 150ms suggestion. Test updated to assert 200.
2. **`IconButton` default hitSlop = 11** (UI-SPEC §10.3). ARCH §3c suggested `8`, which makes a 22pt icon expose only a 38pt touch target. Raised to 11 so the icon reaches 44pt — the iOS minimum.
3. **ORB rgba strings are spaced** (`'rgba(88, 86, 214, 0.70)'`). Matches the electron source verbatim — ARCH §2.2 had transcribed them without spaces.
4. **`BookCover` sizes: sm=48, md=96, lg=144** (UI-SPEC §7f). ARCH §3f matches; prompt mentioned different numbers but UI-SPEC wins.
5. **`BookCover` fallback colour is hash-deterministic** (UI-SPEC §7f). 8-colour palette indexed by `title.charCodeAt` sum.
6. **`ColorTokens` is an explicit structural type, not `typeof colorsLight`**. Required so `colorsDark`'s literal hex values satisfy the same alias (otherwise `'#000000' !== '#FFFFFF'` literal-type clash). Test that pins `Object.values(palette)` was widened with a `Record<string, Record<string, string>>` cast.
7. **`Sheet.tsx` uses `index={isOpen ? 0 : -1}`**, not pure-imperative `expand()/close()`. The bottom-sheet test mock honours the `index` prop to decide whether to render children; pure-imperative wouldn't reach the test mock's rendering branch. Real device behaviour identical because gorhom syncs `index` ↔ ref calls.
8. **`Sheet.tsx` does NOT mount `BottomSheetModalProvider`** (ARCH §1.1 risk). Uses plain `BottomSheet` to match the root layout's existing state (no provider). Phase 3 may switch to `BottomSheetModal` if it adds the provider.
