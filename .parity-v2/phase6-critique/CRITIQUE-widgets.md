# Floating Widgets — UX Critique (Phase 6)

## Summary
Floating widgets generally follow the Apple-Books recipe (BlurView GlassDisk, shadow-outside / clip-inside pattern, Reanimated shared values) but ship with several real layering, safe-area, and a11y defects. Top risks: hardcoded 49pt tab-bar height (wrong on iPad / large text), GlobalMiniPlayer still floats high on non-tab stack routes (chat detail), and the orb + voice launcher overlap the bottom toolbar at the same `zIndex: 20`, masking taps. Reduce Motion is wired into useTheme correctly, but several widgets still trigger Reanimated repeats before checking it.

## Severity legend
- **P0** — Visible defect in default device / common path; ships if not fixed.
- **P1** — Breaks polish or A11y or non-iPhone hardware; should fix before parity ship.
- **P2** — Latent bug, drift, or minor visual nit.
- **P3** — Hygiene only.
