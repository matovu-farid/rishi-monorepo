## Bug Summary
`prefsStore.test.ts` `hydrate()` tests (L24-44) only assert one of the
three `getStoreValue` IPC calls and one of the three resulting state
fields. Production `hydrate()` (prefsStore.ts:41-51) reads three keys
(`voiceChatLanguage`, `voiceChatVisionEnabled`, `ttsVisualCueEnabled`)
and writes three fields. A regression that swaps a key string, drops
one of the IPC reads, or wires the wrong boolean to the wrong field
will pass the suite.

## Tester Analysis
Production:

```ts
// prefsStore.ts:41-51
async hydrate() {
  const raw = await window.electron.getStoreValue('voiceChatLanguage')        // L42 — covered
  const next: AllowedLanguage = isAllowedLanguage(raw) ? raw : DEFAULT_LANGUAGE
  const visionRaw = await window.electron.getStoreValue('voiceChatVisionEnabled') // L44 — UNCOVERED
  const cueRaw = await window.electron.getStoreValue('ttsVisualCueEnabled')   // L45 — UNCOVERED
  set({
    voiceChatLanguage: next,
    voiceChatVisionEnabled: typeof visionRaw === 'boolean' ? visionRaw : true, // UNCOVERED
    ttsVisualCueEnabled: typeof cueRaw === 'boolean' ? cueRaw : true           // UNCOVERED
  })
}
```

Test L28 only asserts `expect(window.electron.getStoreValue).toHaveBeenCalledWith('voiceChatLanguage')`.
Because `getStoreValue` is a single mock that resolves the same value
for every call (L25 `mockResolvedValue('es')` applies to all three
invocations), the suite cannot distinguish "called with 3 specific
keys" from "called with 1 specific key". This is a real coverage gap
in user-facing settings that ship today (vision + visual cue both
control reader behavior; vision is wired through to voice chat agent
tool exposure).

Suggested fix: replace the single `mockResolvedValue` with
`mockImplementation((key) => ...)` returning per-key values, then
assert (a) all three IPC calls happened with the right keys and
(b) all three state fields landed with the right values. Also add a
test for the "non-boolean visionRaw / cueRaw falls back to `true`"
branch — currently the type-guard at L48-49 is uncovered.
