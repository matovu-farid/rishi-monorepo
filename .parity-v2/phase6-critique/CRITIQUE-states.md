# Phase 6 Critique — Empty / Error / Loading States & Edge Cases (mobile)

## Summary
The happy paths feel polished, but every degraded path leaks: cover-extraction, indexing, sync triggers, R2 uploads, conversation-loading and search-filtering all swallow errors into `console.warn` with no UI. The library has no search-empty / filter-empty state, no skeleton during initial DB read, and the Conversation tab silently lists "Unknown Book" rows for deleted/unsynced books. Reader load failures show a six-word grey label with no retry; mic permission denial is also a silent no-op in voice chat.
