# Dioxus Desktop App — Plan 1: Project Scaffold + Database + App Shell

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up a compiling Dioxus desktop app with Diesel SQLite database, all migrations, models, and a basic two-route app shell (library + reader stub).

**Architecture:** Single Rust binary using Dioxus 0.6 desktop (webview renderer). Diesel ORM with SQLite in WAL mode, r2d2 connection pool. Dioxus Router with two routes. Global state via context-provided signals.

**Tech Stack:** Dioxus 0.6, Diesel 2 (SQLite), r2d2, serde, tokio, anyhow, dirs, uuid

use diesel::sqlite::SqliteConnection;
use diesel::Connection;
use diesel_migrations::{embed_migrations, EmbeddedMigrations, MigrationHarness};
use std::path::PathBuf;

use diesel::r2d2::ConnectionManager;
use r2d2::Pool;
use std::sync::OnceLock;

/// Runs PRAGMA statements on every new SQLite connection from the pool.
#[derive(Debug)]
struct SqlitePragmaCustomizer;

impl r2d2::CustomizeConnection<SqliteConnection, diesel::r2d2::Error>
    for SqlitePragmaCustomizer
{
    fn on_acquire(
        &self,
        conn: &mut SqliteConnection,
    ) -> Result<(), diesel::r2d2::Error> {
        use diesel::RunQueryDsl;
        diesel::sql_query("PRAGMA busy_timeout=5000;")
            .execute(conn)
            .map_err(diesel::r2d2::Error::QueryError)?;
        diesel::sql_query("PRAGMA journal_mode=WAL;")
            .execute(conn)
            .map_err(diesel::r2d2::Error::QueryError)?;
        Ok(())
    }
}

pub type DbPool = Pool<ConnectionManager<SqliteConnection>>;

pub static DB_POOL: OnceLock<DbPool> = OnceLock::new();

const MIGRATIONS: EmbeddedMigrations = embed_migrations!();

/// Get a connection from the global pool.
pub fn get_conn() -> Result<r2d2::PooledConnection<ConnectionManager<SqliteConnection>>, String> {
    let pool = DB_POOL.get().ok_or("Database pool not initialized")?;
    pool.get().map_err(|e| {
        tracing::error!("Connection pool exhausted: {}", e);
        format!("Database connection unavailable: {}", e)
    })
}

/// Get the database file path in the platform-specific app data directory.
fn db_path() -> anyhow::Result<PathBuf> {
    let mut path = dirs::data_dir()
        .ok_or_else(|| anyhow::anyhow!("Could not determine app data directory"))?;
    path.push("org.fidexa.rishi");
    std::fs::create_dir_all(&path)?;
    path.push("rishi.db");
    Ok(path)
}

/// Initialize the database: run migrations, create connection pool, set global.
pub fn setup_database() -> anyhow::Result<()> {
    let db_path = db_path()?;
    let conn_url = db_path.to_string_lossy().to_string();

    // Run migrations on a direct connection first
    let mut conn = SqliteConnection::establish(&conn_url)
        .map_err(|e| anyhow::anyhow!("Failed to connect to SQLite: {}", e))?;
    conn.run_pending_migrations(MIGRATIONS)
        .map_err(|e| anyhow::anyhow!("Failed to run migrations: {}", e))?;

    tracing::info!("Database initialized at {}", conn_url);

    // Build connection pool
    let manager = ConnectionManager::<SqliteConnection>::new(&conn_url);
    let pool = Pool::builder()
        .max_size(10)
        .min_idle(Some(2))
        .connection_timeout(std::time::Duration::from_secs(30))
        .connection_customizer(Box::new(SqlitePragmaCustomizer))
        .build(manager)?;

    // Backfill sync_ids for any books missing them
    {
        let mut conn = pool.get()?;
        backfill_sync_ids(&mut conn)?;
    }

    DB_POOL
        .set(pool)
        .map_err(|_| anyhow::anyhow!("DB_POOL already initialized"))?;

    Ok(())
}

/// Backfill sync_id with UUID v4 for books missing one.
fn backfill_sync_ids(conn: &mut SqliteConnection) -> anyhow::Result<()> {
    use diesel::prelude::*;

    #[derive(diesel::QueryableByName)]
    struct BookIdRow {
        #[diesel(sql_type = diesel::sql_types::Integer)]
        id: i32,
    }

    let rows: Vec<BookIdRow> =
        diesel::sql_query("SELECT id FROM books WHERE sync_id IS NULL")
            .load(conn)?;

    for row in &rows {
        let new_uuid = uuid::Uuid::new_v4().to_string();
        diesel::sql_query("UPDATE books SET sync_id = ?1, is_dirty = 1 WHERE id = ?2")
            .bind::<diesel::sql_types::Text, _>(&new_uuid)
            .bind::<diesel::sql_types::Integer, _>(&row.id)
            .execute(conn)?;
    }

    if !rows.is_empty() {
        tracing::info!("Backfilled sync_id for {} books", rows.len());
    }

    Ok(())
}

/// Set up an in-memory database for tests. Returns the pool.
#[cfg(test)]
pub fn setup_test_database() -> DbPool {
    let mut conn = SqliteConnection::establish(":memory:")
        .expect("Failed to create in-memory SQLite connection");
    conn.run_pending_migrations(MIGRATIONS)
        .expect("Failed to run migrations");

    let manager = ConnectionManager::<SqliteConnection>::new(":memory:");
    Pool::builder()
        .max_size(1)
        .build(manager)
        .expect("Failed to build test pool")
}

### Task 6: Initialize database on app startup

**Files:**
- Modify: `apps/dioxus/src/app.rs`

- [ ] **Step 1: Call setup_database from RootLayout**

Update `apps/dioxus/src/app.rs` — add database initialization to `RootLayout` using `use_future`:

```rust
use dioxus::prelude::*;
use rishi_dioxus::db;
use rishi_dioxus::state::auth::AuthState;
use rishi_dioxus::views::{library::Library, reader::Reader};

#[derive(Routable, Clone, PartialEq)]
#[rustfmt::skip]
enum Route {
    #[layout(RootLayout)]
        #[route("/")]
        Library {},
        #[route("/books/:id")]
        Reader { id: i32 },
}

#[component]
pub fn App() -> Element {
    rsx! {
        document::Stylesheet { href: asset!("/assets/main.css") }
        Router::<Route> {}
    }
}

#[component]
fn RootLayout() -> Element {
    use_context_provider(AuthState::new);

    let db_ready = use_signal(|| false);

    // Initialize database once on startup
    use_future({
        let mut db_ready = db_ready.clone();
        move || async move {
            match db::setup_database() {
                Ok(()) => {
                    tracing::info!("Database ready");
                    db_ready.set(true);
                }
                Err(e) => {
                    tracing::error!("Failed to initialize database: {}", e);
                }
            }
        }
    });

    if !db_ready() {
        return rsx! {
            div { class: "loading-screen",
                p { "Loading..." }
            }
        };
    }

    rsx! {
        div { class: "app-root",
            Outlet::<Route> {}
        }
    }
}
```
