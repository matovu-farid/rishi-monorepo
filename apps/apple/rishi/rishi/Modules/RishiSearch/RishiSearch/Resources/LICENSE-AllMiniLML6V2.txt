Vendored Core ML port of sentence-transformers/all-MiniLM-L6-v2
================================================================

Source repo: https://github.com/Abhishek6353/AllMiniLML6V2-coreml
Vendored on: 2026-06-14 for Phase 25-04 of apps/apple (Rishi for Apple)

The Core ML model file `AllMiniLML6V2.mlmodel` was generated by the upstream
`convert_minilm_to_coreml.py` script from
`sentence-transformers/all-MiniLM-L6-v2` (Hugging Face). The pooling +
L2-normalization wrapper is baked into the model graph; the model accepts
`(input_ids, attention_mask)` tensors of shape `[1, 64]` int32 and returns a
single 384-dim L2-normalized embedding (`var_570`).

The WordPiece tokenizer code in
`Sources/RishiSearch/Embedder/MiniLMTokenizer.swift` was ported from the
upstream `MiniLMTokenizer.swift` (Sources/Utils/MiniLMTokenizer.swift in the
Abhishek6353 repo) with the following local changes:
  - hoisted to `internal struct MiniLMTokenizer` matching plan 25-04 interface
  - vocab loader takes a URL (not a bundle subpath) to keep the seam testable
  - default maxLength is 64 to match the vendored .mlmodel's compiled
    sequence-length input shape (the upstream conversion script defaults
    seq_len=64).
