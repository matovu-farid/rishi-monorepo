SIGN-IN FLOW
- Sign in with Apple is the only test path. No shared credentials are needed; the reviewer's Apple ID is sufficient.
- Google Sign-In is also available but Apple is the recommended review path.
- Account deletion is available in Settings → Account → Delete Account. This calls our worker which performs Apple /auth/revoke server-side, then deletes the user row.

FIRST-RUN CONTENT
- A sample EPUB ("The Sample Book") ships in the bundle and is auto-installed into the library on first launch. The reviewer does not need to import their own content to exercise the reader, highlights, chat, or read-aloud surfaces.

VOICE CHAT (PRO FEATURE)
- Real-time voice chat is gated on a Rishi Pro entitlement. In production this is a paid subscription managed at rishi.fidexa.org under our pending Reader App entitlement (External Link Account Entitlement).
- For App Review: the build submitted by this lane is a DEBUG configuration that honors the X-Dev-Bypass header. The reviewer can exercise voice chat by tapping Settings → Developer → Enable Dev Bypass. This toggle is compiled out of Release builds and is documented at apps/apple/docs/APP-STORE-METADATA.md.
- If the reviewer prefers, we can provide a TestFlight build with the bypass pre-enabled — contact the email above.

UNIVERSAL LINKS
- Universal Links to https://rishi.fidexa.org/book/<id> are wired in the app but the worker-side AASA endpoint is not yet active in production. Deep links via rishi:// custom scheme still work from the simulator.

BILLING
