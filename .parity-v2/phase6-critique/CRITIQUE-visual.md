# Visual Design Critique — Apple Books Parity (Code-Level)

## Summary
The theme module is solid (proper iOS semantic colors, hairlines, SF system fonts), but the **Library tab and a few primitives bypass it entirely**, using Tailwind grays, hardcoded brand hex, Material shadows, and a Material FAB that breaks the Apple Books aesthetic. Reader chrome correctly references tokens but ships **no real BlurView** — toolbars use an opaque 95% rgba fallback, so vibrancy is missing on the very surfaces Apple Books treats as glass. The accent color (`#0a7ea4` teal) and shipping the `display-large` style at `fontWeight: 600` (HIG calls for 700/heavy on Large Title) also pull the visuals away from "premium iOS".
